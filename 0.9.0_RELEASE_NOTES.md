# 0.9.0 press — Bring your history, keep your rhythm

This release opens a careful path from Anki to ikna without asking anyone to throw away years of work.

## What’s new

- **Anki Bridge.** Pick an `.apkg` on the phone, inspect a compatibility report, and import supported decks locally.
- **History comes with you.** Up to the newest 100,000 usable review events are mapped into ikna’s review log and replayed through FSRS-6.
- **Safe by construction.** The original package is never modified, nothing is uploaded, SQLite is opened read-only, and imported HTML/JavaScript is never executed.
- **Honest compatibility.** Basic, reverse, cloze and ordinary text templates are supported. Media and unsupported behavior are simplified, skipped and counted instead of being silently guessed.
- **Atomic import and stable re-import.** A failed package writes nothing; importing the same collection again replaces its deterministic ikna packs rather than duplicating them.
- **Ink is the new beginning.** Clean installs now start with the Ink palette. Existing palette choices stay untouched.
- **A gentler return.** Return mode now talks about a finite plan for today and quiet adaptation — not debt, backlog or a recovery countdown.
- **Six complete translations.** The new flow is available in Russian, English, Polish, Spanish, French and German.

## Compatibility limits

The first bridge accepts `collection.anki2`, `collection.anki21` and `collection.anki21b` entries that expose the classic `col / notes / cards / revlog` schema with JSON model and deck metadata. Raw SQLite and Zstandard-compressed collections are supported. Unknown modern schemas are rejected before anything is written.

Deliberate safety ceilings: 300 MiB package, 512 MiB extracted collection, 20,000 ZIP entries, 50,000 active cards and 100,000 newest review rows. Suspended and buried cards are not imported. Binary media, MathJax/image-occlusion fidelity, selective-deck preview and Anki export are specified for follow-up rather than half-shipped here.

## Install

Use the **arm64-v8a** APK on modern Android phones. The **armeabi-v7a legacy32** APK is only for older 32-bit devices.
