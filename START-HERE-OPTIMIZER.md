# Локальный оптимизатор FSRS

Это полный репозиторий поверх предыдущего архива с GRADING, а не набор отдельных
файлов. Версия приложения **не изменена: 0.10.0 press / 200100000**.

## Проверка в приложении

Настройки → обучение/нагрузка → **Локальная настройка FSRS**.

1. Нажмите **Рассчитать по истории**. Расчёт идёт локально в фоновом потоке;
   уход с экрана не отменяет его. Есть отдельная отмена.
2. До 500 проверяемых ответов будет нормальный отказ «мало истории». Повторы
   раньше суток воспроизводятся, но не участвуют в проверочной метрике.
3. При отсутствии улучшения стандартные веса и ранее применённый результат
   не заменяются. Сохраняются вердикт, обе потери, количество ответов и дата.
4. Принятый результат нужно отдельно **применить**. Автоматического включения
   или замены предыдущего расчёта нет.
5. Переключатель возвращает стандартные веса сразу. Действие — только на
   следующие ответы; существующие даты, история и план дня не переписываются.

Полный повторный расчёт ограничен 30 днями. Автоматический ежемесячный запуск
не добавлен: новый расчёт вызывается явно. `desiredRetention` не оптимизируется.

## Перед установкой

Перенесите в GitHub всё содержимое `ikna-main`, включая скрытую `.github`.
Запустите `grading-validation` либо обычную сборку; дождитесь зелёного CI.
Затем сделайте резервную копию и сначала проверьте приложение на временном профиле.
Версия базы меняется **7 → 8** только для хранения параметров ответа; это не
повышение версии приложения. Старые схемы и назначенные карточки не переписаны.

Добавлены JVM-тесты оптимизатора и его подключения, проверка миграции на эмуляторе,
восстановления смешанной истории, undo, отмены, перезапуска и ошибок хранения.
Синтетические принятые результаты в тестах проверяют только подключение, не пользу.
Не обходите порог 500 и не импортируйте тестовые фикстуры как настоящую историю.

Локально выполнены 27 Python/SQLite-проверок, проверка локализаций, фикстур,
схем, YAML, полного архива и применения патча к предыдущему архиву.
**Gradle/Kotlin/KSP, JUnit и Android-эмулятор здесь не запускались:** среда не смогла
скачать зависимости компилятора. Их результат должен подтвердить приложенный CI;
сборка с первого раза не выдаётся за уже доказанный факт.
