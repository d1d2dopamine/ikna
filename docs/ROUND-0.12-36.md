## Why this differs from the old small witness

The input is the complete hash-bound admitted pool, not a sample of exported
selected contexts. Global ranks use all deduplicated original contexts for the
8 learning languages, including other meaning languages, in the original
context-key/token first-seen tie order. Only candidate evidence and analysis are
restricted to the 13 needed pairs. Ranking the subset would change levels and
invalidate the comparison.

The original bounded evidence and allocation must first reproduce every affected
historical baseline count. A complete qualifying graph then distinguishes raw
admissible contexts lost from bounded evidence from contexts owned by baseline
primary/alternate reservations. A conservative additive witness locks every
baseline target and context assignment. It adds a missing target only if the
unchanged chooser supplies exactly 3 distinct valid unowned contexts. It never
removes alternatives, shares contexts, rewrites text or changes source gates.

This yields a lower-bound feasibility witness, not a maximum, a semantic accuracy
certificate or an accepted policy revision. Zero additions would not prove that
quality-preserving remapping is impossible. Primary-only maximum matching is not
presented as same-profile recovery and the old Round 15 experiment is not repeated.
