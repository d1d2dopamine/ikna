## Reproduction and scope

The unchanged `tools/catalog/selection_evaluate.py` was executed over the full
file with the saved baseline preview/report and exact pins. It regenerated the
workflow quality report byte for byte; hash and pipeline/environment pins are in
`SNAPSHOT.json`. Retained report bytes remain in `../everyday-round12/`.

`CENSUS-ANALYSIS.py.gz` and `ALLOCATION-ANALYSIS.py.gz` preserve the exact one-off
read-only session analysis drivers and their recorded hashes. They use the captured
scratch ROOT and derived `validation/round15` paths: adjust ROOT to replay in a new
workspace. Input extraction creates `input/selected-everyday.jsonl.gz` and
`input/EVERYDAY-SELECTION.json`. Use a fresh `census` output directory (the driver
creates its disposable SQLite tables); run census first, then the allocation
driver with `tools/catalog` on PYTHONPATH. Changing ROOT changes the analysis
script hash; input identity and census totals must remain unchanged. These drivers
are evidence recipes, not a new production builder or workflow.

Counts cover every selected row. The pl-ko witness uses 81 retained bilingual
pairs, including already existing reverse-direction evidence, and exported Polish
surface ranks. Its raw intermediate witness is reproducible from the full file,
not packaged as another corpus. It is not all discarded raw input or a global
optimal-allocation claim. Source sentences and global targets remain unchanged.
