# Ikna study demo

Record the regular desktop study flow using a small demo deck and a separate
profile with a prepared review history. Use the normal theme and controls.

| Time | On screen |
| --- | --- |
| 0–5 s | Open a deck from the daily plan. Hold on the «Новая карточка» label and one readable sentence. |
| 5–12 s | Reveal the answer. Leave both grades on screen for a moment, then click one grade to show the transition. |
| 12–19 s | Reveal a familiar card, then swipe it to grade. Let the next card settle before cutting. |
| 19–26 s | Grade the final card. Hold on the completed plan and its next scheduled review. |
| 26–34 s | Switch to footage from a demo profile returning after a break. Show the welcome and press «Продолжить занятие». |

Use the same example on both sides of the first card. Keep the cursor visible,
hide notifications, and check that the captions and next review time are readable
at the size used in the release post. Capture the return state from actual saved
review history so the footage matches what learners will see.
