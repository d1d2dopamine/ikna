# Поиск источников pl↔ko: результат ограниченного запуска

Готов небольшой проверенный инструмент и выполнен реальный запуск. Он не создаёт, не переписывает и не переводит тексты карточек.

Три API-запроса последнего запуска заняли 14,16 секунды и получили 967 667 байт метаданных. Найдены 22 записи OPUS о парных архивах и 30 записей репозиториев Hugging Face; поиск по имени дал ноль. Это 52 поисковых результата, а не 52 подходящих корпуса. Поиск ограничен первой страницей HF, без обхода продолжения.

У 29 записей имя не сопоставилось с известным семейством. Такие записи видимы для проверки; это не доказательство новизны. Известные семейства, версии и поднаборы не скрываются. Вес парных метаданных выше, чем простого совместного упоминания языков. Оценка задаёт очередь исследования, а не качество или правовую пригодность.

Три источника проверены подробнее:
- tldr-pages: лицензия страниц CC BY4.0 есть, но правила допускают помощь машинного перевода. Человеческое происхождение нужного поднабора не подтверждено; материал технический.
- UDHR: интересный след с независимо опубликованными переводами одной декларации. Нужны авторство и права именно польского и корейского текстов. Лицензия упаковки Unicode этого не доказывает; страница OHCHR вернула403. Даже при разрешении это небольшой тематический ресурс для World/Knowledge, а не доказанное решение Everyday.
- Apple HAT: тексты переведены нейросетью, люди размечают ошибки. Человеческая разметка не делает перевод человеческим; источник не подходит под условие владельца.

Также по сохранённым метаданным понижены два ложных попадания: карточка модели и набор французских переводов песен с широкими языковыми тегами. Наблюдения привязаны к конкретным ревизиям; новые версии не исключаются автоматически.

Итог:0 очищенных для выборки новых источников среди трёх проверенных,0 загрузок архивов корпусов,0 намеренно запрошенных строк датасетов,0 принятых карточек. Непроверенные результаты остаются в списке. Это не утверждение, что подходящих источников вообще нет. Сырые полные метаданные API иногда содержат встроенные примеры; они исключены из выдачи. Для воспроизведения приложены только очищенные идентификаторы, ревизии, теги и парные числовые метаданные.

Проверки:21 тест нового инструмента и22 существующих теста происхождения WMT; всего43 прошли. Офлайн-повтор очищенных метаданных воспроизводит LEADS.json и GAPS.json побайтно. Независимый разбор обнаружил и помог исправить учёт перенаправлений, слишком сильную формулировку о текстах и веса языковых тегов; история исправлений сохранена.

Стоимость указанного финального запуска —3 публичных HTTP-запроса без платных API. До него были ещё2 контрольных запуска по3 запроса, а также отдельное исследование страниц источников. Поэтому3 не является общей стоимостью всего этапа. Сетевой timeout30 секунд относится к сокету; весь фактический запуск дополнительно ограничен120 секундами и одним CPU.

Все изменения интерфейса до Round41 сохранены. Новые файлы относятся только к поиску и отчётам; существующий план дополнен. Форматы каталога, допуск источников и алгоритм отбора не изменены. ZIP не содержит корпусов и реальных примеров карточек.

Следующий конкретный вопрос — права и авторство двух переводов UDHR; затем, только при подтверждении, имеет смысл небольшой замер соответствия и полезных контекстов. Автоматическое расширение поиска, скачивание остальных результатов и создание переводов не запускаются.
