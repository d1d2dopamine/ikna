Проверка анимации сворачивания Ikna в Windows

Это диагностика, а не исправление. Видео не требуется.
Скрипт читает только PID/заголовок окна Ikna, его оконные флаги и системный
флаг анимации сворачивания/восстановления. Он не меняет настройки Windows,
не управляет окном, не ставит перехватчики, ничего не скачивает и не отправляет.
Права администратора не нужны. Содержимое карточек и базы данных не читается.
Add-Type компилирует маленький локальный помощник для чтения Windows API;
ничего устанавливать не нужно. Результат выводится только в PowerShell.

1. Откройте нужную сборку Ikna. Восстановите окно из панели задач; выйдите
   из полноэкранного режима. Для первого замера используйте обычное окно,
   не развёрнутое на весь экран. Пока идёт чтение, не закрывайте Ikna.

2. Откройте обычный PowerShell в папке исходников. Команда:
   .\tools\diagnose-window-minimize.ps1

   Если получены только два отдельных TXT-файла, сначала прочитайте файл
   Ikna-window-minimize-probe.txt, затем сохраните его копию с именем
   diagnose-window-minimize.ps1. В PowerShell из той же папки выполните:
   .\diagnose-window-minimize.ps1

   Скрипт покажет только окна с названием Ikna и попросит ввести PID
   нужного окна, даже если найдено одно. PID — число в столбце Id.
   Если окон несколько и непонятно, какое нужно, ничего не угадывайте:
   нажмите Ctrl+C. В Диспетчере задач раскройте нужную Ikna и выберите
   «Перейти к подробностям», затем сверьте PID. Можно также взять PID
   из первой строки logs/window-surface.log именно текущего DEV-запуска.
   Для уже проверенного PID команда выглядит так (1234 замените своим):
   .\tools\diagnose-window-minimize.ps1 -IknaProcessId 1234

   Если политика Windows запрещает скрипт или Add-Type, остановитесь
   и пришлите текст ошибки. Не меняйте ExecutionPolicy, не запускайте
   от администратора и не отключайте защиту ради этой проверки.

3. Скопируйте результат начиная со строки «Ikna minimize probe v1».
   Отдельно проверьте вручную на этом же окне:
   а) сверните кнопкой «−» внутри Ikna, затем восстановите из панели задач;
   б) удерживая Shift, нажмите правой кнопкой на значке Ikna в панели задач
      и выберите «Свернуть» в оконном меню, затем восстановите окно.
      При группе окон выберите именно нужное окно; если команда недоступна,
      так и напишите, не заменяя её командой «Показать рабочий стол».
   Для каждого способа достаточно ответа «анимация есть» / «анимации нет».
   Укажите сборку и способ запуска: Hot Reload или установленная программа.
   Если сравниваете с GitHub Desktop, используйте ту же Windows-сессию.

Если анимация работает только через панель задач, это поможет отделить
путь кнопки от настройки самого окна. Если не работает ни там, ни там,
оконные флаги помогут проверить нативную рамку. Само наличие или отсутствие
флага ещё не доказывает причину; исправление здесь не заявлено.

Проверка подготовлена по исходникам Round 49. Приложение использует
Compose 1.8.2 и Skiko 0.9.4.2; фактическое поведение Windows ещё не проверено.
Скрипт не запускался на Windows при подготовке; возможную ошибку пришлите
как есть. Он не требует видео или доступа помощника к вашему компьютеру.
